# Python Uploader For mBot2

**Язык / Language:** [Русский](README.md) · [English](README.en.md)

Загрузка Python-программ на **mBot2 / CyberPi** по USB.

<img width="756" height="696" alt="image" src="https://github.com/user-attachments/assets/06297a7b-e789-4df0-867b-be58c0e414ba" />

Программа находит робота на COM-порту, переводит плату в режим записи и отправляет файл `.py` на робота — туда же, куда его пишет редактор Makeblock. После загрузки программа хранится на плате и работает без компьютера.

---

## Скачать (Windows)

1. Откройте [Releases](../../releases) этого репозитория.
2. Скачайте:
   - `Python_Uploader.exe`
   - `Python_Uploader.exe.sha256` (контрольная сумма)
3. Проверьте целостность файла (PowerShell):

```powershell
Get-FileHash .\Python_Uploader.exe -Algorithm SHA256
Get-Content .\Python_Uploader.exe.sha256
```

Хеши должны совпасть (в `.sha256` указан ожидаемый SHA256 и имя файла).

## Как пользоваться

1. Подключите робота по USB и включите питание.
2. Запустите `Python_Uploader.exe`.
3. Выберите файл программы `.py` — кнопкой **Обзор**, перетаскиванием в окно или передав путь аргументом.
4. В списке портов выберите **CyberPi / mBot2**.
5. Нажмите **Загрузить на робота** (или `Ctrl+Enter`).

### Запуск с файлом из командной строки

```text
Python_Uploader.exe "C:\path\to\program.py"
```

### Возможности интерфейса

- Список USB-портов с пометкой CyberPi / mBot2
- Журнал загрузки (сохранение, очистка, метки времени)
- Темы: как в системе / светлая / тёмная
- Язык: русский / English
- Отмена записи во время загрузки

Настройки сохраняются в `%LOCALAPPDATA%\Python_Uploader\`.

## Проверка перед загрузкой

| Требование | Пояснение |
|------------|-----------|
| Windows 10/11 | Сборка рассчитана на Windows |
| mBot2 / CyberPi | Питание включено |
| USB-кабель с передачей данных | Зарядные кабели не подойдут |
| Драйвер CH340 | VID:PID `1A86:7523` |
| Закрытый mLink | И другие программы, занимающие тот же COM-порт |

## VS Code

Файлы `mbot2.py`, `mbuild.py`, `cyberpi.py`, `pocket.py` и `event.py` — сигнатуры методов. Они полностью повторяют официальное API mBot2 / CyberPi и нужны, чтобы программу было удобно писать в VS Code: редактор показывает подсказки, автодополнение и проверяет вызовы. На компьютере эти функции ничего не выполняют и на робота не влияют. На плате уже есть настоящие модули прошивки, поэтому сами файлы сигнатур туда загружать не нужно.

<img width="808" height="364" alt="advice" src="https://github.com/user-attachments/assets/471640b7-d5ae-49a3-bbe2-68767372a4f7" />

В проекте есть приложение для привязки кнопки статус-бара к запуску приложения, а так же запуск по горячей клавише F5.
Tasks запускает `Python_Uploader.exe` с путём к открытому `.py`. Если окно уже открыто, подставляется новый файл.

## Важно

- Не загружайте на плату файлы `cyberpi.py`, `mbot2.py`, `mbuild.py`, `event.py`, `pocket.py` — программа их не пропускает.
- В контроллер пишется файл `/flash/main.py`, как в редакторе Makeblock.

## Предупреждение Windows SmartScreen

Exe **не подписан** сертификатом Authenticode, поэтому Windows может показать предупреждение:

> Windows защитил ваш компьютер

Это ожидаемо для небольшой утилиты без платной подписи кода. Если файл скачан с этой страницы релизов и SHA256 совпал:

1. Нажмите **Подробнее**
2. Затем **Выполнить в любом случае**

Не скачивайте программу с посторонних зеркал — сверяйте хеш с релизом.
